# FastAPI E-Commerce API

A backend REST API for an e-commerce platform built with **FastAPI**.

## Tech Stack

* Python
* FastAPI
* PostgreSQL
* SQLAlchemy
* JWT Authentication
* Razorpay
* Pytest
* Postman

## Features

* User registration and login
* JWT-based authentication
* Product management
* Shopping cart
* Order management
* Inventory management
* Razorpay payment integration
* Admin functionality

This project is being built step by step to strengthen backend development, database design, API development, authentication, and payment integration skills.
